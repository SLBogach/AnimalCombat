# Unity Replay Viewer — редактирование сцены v0.1

Открой `UnityClient/AnimalCombat/Assets/ReplayViewer/Scenes/ReplayViewer.unity`. В Hierarchy группа **Arena & Fighters** содержит фон арены как `SpriteRenderer`, две границы проекции записанных позиций и экземпляры префабов `BearFighter` / `KangarooFighter`.

У каждого зверя `ReplayAnchor` получает позицию из replay при воспроизведении. Для художественного смещения зверя в кадре меняй дочерний `ArtRoot`; для настройки тела и анимации — `BodyPivot`, `HeadPivot`, `ArmPivot`, `FrontLegPivot`, `RearLegPivot` и, у кенгуру, `TailPivot`. Изменения префаба через **Open Prefab** применяются к его экземпляру в сцене. Если двигать сам `ReplayAnchor` в Edit Mode, его X во время Play будет снова установлен из JSON; Y можно использовать для настройки уровня земли. Позиции `Replay Position 0` и `Replay Position Max` задают, куда проецируются минимальная и максимальная позиции арены из replay.

Точки экипировки уже вложены в соответствующие части тела: `WeaponGrip`, `TorsoArmor`, `HeadArmor`, `ArmArmor`. Каждая содержит отдельный дочерний объект `... Visual - assign art in Inspector` со `SpriteRenderer`. Назначь готовый спрайт в поле **Sprite**, после чего можно двигать, вращать, масштабировать и анимировать именно этот объект. Пока спрайты оружия и брони отсутствуют в проекте, эти объекты намеренно невидимы; viewer не выдумывает экипировку из replay 0.1.

Движения во время Play находятся в `Assets/ReplayViewer/Animations/Bear/` и `Animations/Kangaroo/`: по 23 редактируемых `.anim` и отдельный Animator Controller для каждого зверя. Открой префаб, выбери его корень и в **Window → Animation → Animation** выбери нужный клип. Ключи меняют `MotionRoot` и pivots частей тела; оружие и броня следуют за соответствующими креплениями. Не добавляй в клипы ключи для `ReplayAnchor`: его X, направление, HP, состояние, победитель и порядок событий приходят из replay JSON. Скорость и пауза replay также управляют Animator. HUD, HP bars, кнопки и телеметрия остаются в UI Toolkit.

`FighterClipPlayer` только выбирает Animator state по событию JSON и возвращает краткие эффекты к ожиданию. Он не задаёт координаты суставов: их ключи хранятся в `.anim`. Для визуальной доводки редактируй клипы в Unity, не правя `ReplayAnimationAuthoring` — эта команда создаёт только недостающие клипы и не перезаписывает существующие.

Команда редактора **Animal Combat → Replay Viewer → Build editable scene** пересоздаёт сценовые объекты и префабы из текущих атласов, затем прикрепляет существующие Animator Controllers. Не запускай её после ручной расстановки/назначения спрайтов без резервной копии: команда заменяет группу `Arena & Fighters` и содержимое обоих префабов. **Create missing animation clips** не пересоздаёт сцену или существующие клипы.
